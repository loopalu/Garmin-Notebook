# Notebook app for Garmin watch

## Notebook-Watch
An app for keeping notes in Garmin watch as a "notebook". The app can store and display text files and also image files. Due to technical limitations from Garmin watch' side, image files will be downscaled both in size and in color quality.

## Notebook-Android
An Android companion app for managing Notebook's files in Garmin watch. It is possible to manage folders, text files and image files.
